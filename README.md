# 🇹🇳 Tunisian Postal Traffic Insights

***Project Overview***

An interactive Power BI dashboard designed to analyze postal traffic across Tunisia, providing insights into incoming and outgoing mail flows and regional performance.

***Objectives***

Analyze incoming and outgoing postal traffic.

Compare postal activity across different regions.

Identify trends and variations in postal flows.

Provide actionable insights through interactive visualizations.

***Tools & Technologies***

Power BI

Power Query

DAX

Data Cleaning & Transformation

Data Visualization

***Key Features***

Interactive dashboards

Regional performance analysis

Incoming vs. outgoing traffic comparison

Net Flow KPI

Dynamic filtering
